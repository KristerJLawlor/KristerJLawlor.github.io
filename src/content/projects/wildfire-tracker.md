## Overview

Wildfire Tracker is a web application that pulls real-time wildfire data from NASA's Earth Observatory Natural Event Tracker (EONET) API and displays it visually on a map. The project demonstrates working with external APIs and presenting geospatial data in a meaningful way.

## Features

- Real-time wildfire data from NASA's EONET API
- Visual map-based display of active fire events
- Fetches and parses live geospatial JSON data

## Tech Stack

- **JavaScript** — application logic and API integration
- **NASA EONET API** — live natural event data source
