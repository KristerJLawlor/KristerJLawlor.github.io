## Overview

Empyrean is a tactics RPG inspired by Fire Emblem and other turn-based strategy games. Built in Unity using C#, the project focuses on grid-based movement, unit management, and turn-based combat systems.

## Features

- Grid-based map and movement system
- Turn-based combat mechanics
- Unit classes and stat systems inspired by classic tactics games

## Tech Stack

- **C#** — gameplay logic, unit systems, and combat mechanics
- **Unity** — game engine, scene management, and rendering
