## Overview

Disclone is a full-stack web application that replicates core Discord functionality. The project covers both frontend UI and backend API development, including real-time communication patterns and user interface design.

## Features

- Discord-inspired UI and navigation
- Frontend built with JavaScript
- Backend API built with TypeScript

## Tech Stack

- **JavaScript** — frontend application
- **TypeScript** — backend API
- **HTML / CSS** — structure and styling
