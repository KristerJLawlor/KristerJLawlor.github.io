## Overview

A game engine built from the ground up using the Vulkan API. Vulkan is a low-level, explicit graphics API that requires the developer to manage GPU resources, render pipelines, synchronization, and memory directly — making this project a deep dive into real-time graphics programming.

## Features

- Vulkan instance, device, and swapchain setup
- Render pipeline and shader management
- GLSL vertex and fragment shaders
- GPU memory management and buffer handling

## Tech Stack

- **C++** — engine core and system architecture
- **Vulkan** — graphics API
- **GLSL** — shader programs
