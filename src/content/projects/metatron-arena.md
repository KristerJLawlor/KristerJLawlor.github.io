## Overview

MetaTron Arena is a networked multiplayer arena shooter built in Unity. The project focuses on real-time multiplayer game networking, handling player connections, game state synchronization, and fast-paced arena combat.

## Features

- Real-time networked multiplayer
- Arena-based combat gameplay
- Custom shaders and visual effects

## Tech Stack

- **C#** — gameplay logic and networking code
- **Unity** — game engine and scene management
- **ShaderLab / HLSL** — custom shaders and visual effects
